# 过流方波信令设计（FB 出口 4053 切 DAC 通路）

- 日期：2026-08-26
- 状态：设计已确认，待转 writing-plans
- 关联：`I301_code/Core/Src/ocd.c`（既有软件过流检测）、`docs/superpowers/specs/2026-08-04-ad-da-processing-path-design.md`（§3.2 JP3、§9.7 FB 导出、4053 选路事实）

## 1. 背景与目的

振镜板检测到过流后，需要通知总控制板切断激光，保证振镜板刹停振镜的过程中激光不持续打在同一个点上。信令载体复用现有 FB 导出线（JB3/JB4 的 FBX/FBY）：

- **正常态**：FB 出口走模拟直通（driver 位置反馈 FB，纯模拟）；
- **过流态**：板载 74HC4053 模拟开关切到 DAC 通路，DAC 输出 **50% 占空比方波**，总控制板识别方波后切激光。

外部约束（用户给定）：

- 现版本总控制板是否有方波检测机制**未知**，本次为"尝试"；新版总控制板将支持自定义协议。因此信令规格由振镜板单方面定义，原则是波形特征鲜明、量程与正常信号同域，便于现有机型识别与将来对端检测。
- 方波幅值取"当前 AD-DA 通路 DAC 输出峰值"的理由 = **量程匹配**（正常时模拟通路反馈幅值与 AD-DA 重建峰值同量级），且因 AD-DA 波形幅值随图案变化，幅值必须**实时跟踪更新**。

## 2. 硬件事实（无需改板）

- JB3/JB4 的 FBX/FBY 脚由 **74HC4053（U10）** 选路：X0/Y0 = driver 位置反馈 FB（模拟直通，driver 页 U3A 输出），X1/Y1 = DA_FBX/DA_FBY（MCU DAC 重建：DAC1_CH2/PA5、DAC4_CH2/PA8 经 OPAMP5）；公共端经 R6/R8 出板。
- 选择脚 A/B = CH-FBX(PB3)/CH-FBY(PB4)；`gpio.c` 已配推挽 + 下拉、**默认低电平 = 选 X0/Y0（模拟直通）**，严禁悬空。
- 因此本设计为**纯固件改动**；默认低 + 下拉同时是 fail-safe 方向：MCU 完全死机时 PB3/PB4 保持低，FB 仍走模拟直通（与现状一致）。
- 附带收益：正常态走模拟直通后，FB 导出线不再经过 12-bit DAC 重建，此前排查过的 MSB major-carry 毛刺注入在 FB 线上消失。

## 3. 与既有 OCD 模块的关系

既有 `ocd.c`（commit 1e2bf86）：ix/iy 连续 peg（==0/==4095）>8 次跳闸，200ms 强制 IN=2048/FB=0 + 1s 检测盲期，挂载为算法槽包装层，跑在 1MHz 管线 ISR 内。

本设计**新增独立模块 `ocd_sig.c/.h`，作最外层算法槽包装**（链：`linear → ocd → ocd_sig`），与 ocd 正交：

- ocd 继续负责命令级软保护，不改；
- ocd_sig 只负责"信令出口"：4053 切换 + 方波生成；
- 触发判据**复用** ocd 的 peg 定义与连续计数语义，但**按轴独立计数**（ocd 现状是 ix/iy 联合 OR，信令需要轴归属）。

## 4. 架构与状态机

每轴一个独立信令状态机实例：

```
SIG_OFF ──(本轴连续 peg > OCD_SIG_TRIP_RUN)──→ SIG_ON
   ↑                                                │
   └──(本轴无 peg 稳定持续 OCD_SIG_RELEASE_MS)───────┘
```

- **SIG_OFF（正常）**：CH 脚低 → 4053 选 X0/Y0 模拟直通；包装层透传内层输出；峰值跟踪并行常跑。
- **SIG_ON（信令）**：本轴 CH 脚高 → 4053 选 X1/Y1；包装层把本轴 FB 通道（X=ch1、Y=ch3）`out[]` 替换为 0↔amp 方波；另一轴 FB 不受影响（**按轴独立切换**；"对端两线都监测"作为协议建议留给新版总控板）。
- **释放 = 防抖型**：无 peg 稳定持续 `OCD_SIG_RELEASE_MS` 才回 OFF；期间再现 peg 清零重计、保持 ON。
- **方波优先**：ocd 在 HOLD 期对内层 FB 的强制 0 会被外层方波覆盖（有意）；IN 通道（ch0/ch2）ocd_sig 不碰，ocd 命令级保护不受影响。

两个边界决策：

1. **峰值样本源 = 原始 ADC `in[1]/in[3]`**（不用重建 out）：不受 ocd HOLD 强制值干扰，peak 跟随真实电流波形；幅值叠加本轴 `comp_value`（重建公式 `y = x + off`，comp 主循环写/ISR 读、对齐加载天然原子，同 task.c 惯例）近似"DAC 输出峰值"。
2. **peg 样本排除 + 幅值地板**：过流样本本身在满量程，计入 peak 会把幅值顶到全量程，违背量程匹配意图，故 peg 样本跳过；静息时过流则 peak≈0、方波不可见，故幅值不低于地板 `OCD_SIG_MIN_AMP`。

状态迁移时直写 GPIO（`HAL_GPIO_WritePin`，寄存器级快，ISR 内安全）；释放计时用 `HAL_GetTick()`，同 ocd.c 惯例。

## 5. 波形生成与峰值跟踪

运行上下文：1MHz 管线 ISR，每半块 32 样本；不新建定时器/DMA/中断源，方波以管线样本率为时基。

**方波**（每轴独立）：样本计数器 `ph` 逐样本自增；输出 = `(ph % P) < P/2 ? amp : 0`，P = 1MHz / `OCD_SIG_FREQ_HZ`。默认 1kHz ⇒ P=1000、半周期 500µs、50% 占空比、单极性 0↔amp（与 FB 静息 0 语义一致）。

**幅值**：`amp = clamp(peak + comp, OCD_SIG_MIN_AMP, 4095)`。

**峰值跟踪**（每轴独立，输入 = 原始 in）：

- 攻击：非 peg 样本且 `sample > peak` ⇒ `peak = sample`（立即）；
- 衰减：预分频每 `OCD_SIG_PEAK_DECAY_DIV` 样本 `peak -= 1`（默认 1024 ⇒ ≈1 code/ms，满量程 ~4s）；
- peg 样本跳过（不攻击、不重置）。

**开销**：OFF 态每样本 ≈ 每轴 2 次 peg 比较 + 1 次峰值比较 + 透传拷贝，与 ocd 同量级，远裕于 32µs 死线；ON 态为常数填充，更便宜。

**已知电气行为（接受，不处理）**：4053 切换瞬间存在 make/break 毛刺；故障态可接受。DAC1_CH2 无缓冲直出、DAC4_CH2 经 OPAMP5，均为现状。

## 6. 参数表（编译期宏，集中 ocd_sig.h）

| 宏 | 默认 | 依据 |
|---|---|---|
| `OCD_SIG_ENABLE` | 1U | 总开关，0 = 编译期整体摘除（回退） |
| `OCD_SIG_FREQ_HZ` | 1000 | 远高于正常电流波形带宽，规则性鲜明，1MHz 整除 |
| `OCD_SIG_TRIP_RUN` | 8U | 同 `OCD_TRIP_RUN` 语义，按轴独立 |
| `OCD_SIG_RELEASE_MS` | 500U | 防抖释放；大于触发窗、小于 ocd 1s 重武装周期 |
| `OCD_SIG_MIN_AMP` | 512U | 幅值地板 ≈0.31V（1LSB≈0.61mV），静息过流方波仍可见 |
| `OCD_SIG_PEAK_DECAY_DIV` | 1024U | ≈1 code/ms，满量程 ~4s 衰减完 |
| `OCD_SIG_FORCE` | 0U | 诊断：1 = 强置两轴 SIG_ON（验信令链，不需真过流）；用完回 0 |

peg 定义复用 ocd 的宏（==0/==4095）；**ADC 量程修复后一处修改**（折返冲顶系 ADC 量程 bug，后续修）。

## 7. 测试、上板与回退

**宿主单元测试（TDD，`tests/ocd_sig/`，WSL gcc 先例，同 tests/ad_da_deglitch）**：

- 状态机：触发（连续 peg>8）、防抖释放、释放期再 peg 清零重计、双轴独立（X peg 不动 Y）、释放后再触发；
- 峰值跟踪：攻击立即、衰减速率、peg 排除、地板、`+comp` 钳位；
- 波形：统计 N 样本 0/amp 分布，验证 1kHz、50% 占空比、amp 取值。

**上板顺序**：

1. `OCD_SIG_FORCE` 诊断宏强置 ON（不需真过流）→ 示波器/串口确认 FBX 出口 1kHz 方波 0↔amp、4053 切路正确、总控板侧 FB 线可见；
2. 信令链确认后，等 ADC 量程修复再联调真过流判据；
3. 既有约束不变（JP3 断开等）。

**回退**：`OCD_SIG_ENABLE=0` 回到现状；OFF 态为纯透传 + 峰值计算，对现有管线零副作用。

## 8. 已知边界与 deferred

- **MCU 死机 = 无信令**：命令级软保护的固有边界（与 ocd 相同），硬件级保护仍靠 F1 保险丝 / LM3886 内部限流。不做硬件比较器方案（需改板，尝试阶段成本收益不足）。
- **总控板认不认 = 最大外部未知**：FORCE 先验信令链，再谈检测语义；新版总控板支持自定义协议后细化（含"两线都监测"的轴归属协议）。
- 方波为 0↔amp 单极性；若对端需要双极性/其他编码，仅改填充函数，状态机不动。
