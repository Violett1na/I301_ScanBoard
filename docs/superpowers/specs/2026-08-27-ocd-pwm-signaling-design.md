# 过流 PWM 信令设计（4053 切 FB 出口 + 硬件定时器方波）

- 日期：2026-08-27
- 状态：设计已确认，待转 writing-plans
- 关联：`I301_code/Core/Src/ocd.c`（既有软件过流检测，本设计不改）、`docs/superpowers/specs/2026-08-04-ad-da-processing-path-design.md`（§3.2 JP3、§9.7 FB 导出、4053 选路事实）
- 取代：`2026-08-26-ocd-squarewave-signaling-design.md`（DAC 方波方案，已作废删除；旧文可查 `git show 06df0ac:docs/superpowers/specs/2026-08-26-ocd-squarewave-signaling-design.md`）

## 1. 背景与目的

振镜板检测到过流后，需要通知总控制板切断激光，保证振镜板刹停振镜的过程中激光不持续打在同一个点上。信令载体复用现有 FB 导出线（JB3/JB4 的 FBX/FBY）：

- **正常态**：FB 出口走模拟直通（driver 位置反馈，纯模拟）；
- **过流态**：板载 74HC4053 模拟开关切到 PWM 通路，FB 出口出 **1kHz、50% 占空、3V3 逻辑摆幅方波**，总控制板识别方波后切激光。

外部约束（沿用旧 spec）：现版本总控制板是否有方波检测机制**未知**，本次为"尝试"；新版总控制板将支持自定义协议，信令规格由振镜板单方面定义，原则是波形特征鲜明、便于对端检测。

**方案演进**：
- v1（旧 spec，已作废）：过流时 4053 切 DAC 通路，方波由管线 ISR 填样本生成，幅值实时峰值跟踪。
- v2（本设计）：过流时 4053 切 PWM 通路，方波由硬件定时器（TIM2/TIM1）**上电常开**产生，软件只切 GPIO、不填样本；幅值固定 3V3 逻辑摆幅，不做峰值跟踪。

**本轮（2026-08-27）范围收敛记录**：
- 曾探索"过流时把 IN 通路波形频率降一半（时域拉伸）以保护振镜"。结论：**物理上不可持续**——vx/vy 是总控板持续送来的实时模拟流（每通道 250k 样本/秒），时域拉伸要求输出以输入到达速率的一半消费样本，堆积以 ≈125k 样本/秒（≈250KB/秒/通道）发散，128KB RAM 仅能支撑 ~200ms；且已确认**总控板在报警后仍照常发送命令波形**（不会配合降速）。故 IN 侧保护本次不做，IN 通路保持原样。
- 用户已表达废弃 ocd.c 现有钳位行为（跳闸后强制 IN=2048/FB=0）的意向，但**本次不动 ocd.c**（过渡期保留既有命令级保护）；废弃与替代一并留待 IN 侧保护重新设计（见 §10）。

## 2. 硬件事实（纯固件改动，无需改板）

- JB3/JB4 的 FBX/FBY 脚由 **74HC4053（U10）** 选路：
  - X0/Y0 = driver 位置反馈 FB（模拟直通，正常态）；
  - X1 = PA5 网（现 DAC1_OUT2 直出，无缓冲）；Y1 = PA8 网（现 OPAMP5 输出，DAC4_CH2 片内接 OPAMP5 同相端、follower）；
  - 公共端经 R6（X）/R8（Y）出板。
- 选择脚：A = CH_FBX（PB3）、B = CH_FBY（PB4）；`gpio.c` 已配推挽+下拉，**默认低电平 = 选 X0/Y0（模拟直通）**，严禁悬空。
- **fail-safe 方向**：默认低+下拉 ⇒ MCU 完全死机时 PB3/PB4 保持低，FB 仍走模拟直通（与现状一致）。
- PA5/PA8 的 ADC 功能（ADC2_IN13 / ADC5_IN1）均未被占用，可安全改作定时器复用输出。
- 定时器资源：
  - **TIM2**：`.ioc` 已有 `MX_TIM2_Init`（现配 PSC=170−1、ARR=99、TRGO=update），MspInit 中 TIM2_IRQn 已使能（优先级 0）但定时器从未启动；task.c 存有 TIM2 中断死代码（README 警示"不得再启用 TIM2 中断"——回调直写 DHR 与 TX DMA 竞争）。本设计复用作 PWM，**不开更新中断**，并把 NVIC 中 TIM2_IRQn 禁掉。
  - **TIM1**：全工程未用，高级定时器；按 task.c 的 `htim6` 先例手工建句柄（`__HAL_RCC_TIM1_CLK_ENABLE` + 手填 Init），`HAL_TIM_PWM_Start` 会处理 MOE。**TIM1 是 16 位定时器（ARR≤65535）**，不能直挂 170000 大周期。
  - 定时时钟 170MHz（APB1/APB2 均 170MHz）⇒ 1kHz 统一取 **PSC=170−1、ARR=1000−1、CCR=500**（170MHz/170/1000=1kHz，50% 占空）；TIM2 虽为 32 位可用大 ARR，但与 TIM1 取完全相同配置，两路常数一致。（2026-08-27 计划阶段修正：初稿 ARR=170000−1 仅适用 32 位定时器，TIM1 放不下。）
- 检测输入：ix = `in[1]`（ADC2/PA0）、iy = `in[3]`（ADC5/PA9），同 ocd。

## 3. 与既有 OCD 模块的关系

既有 `ocd.c`：**保持原样，不改**（过渡期命令级软保护：跳闸后 200ms 强制 IN=2048/FB=0 + 1s 盲期；用户已表态将来废弃，见 §10）。

新增独立模块 `ocd_sig.c/.h`，作**最外层算法槽包装**（链：`linear → ocd → ocd_sig`），与 ocd 正交：

- ocd_sig 只负责"信令出口"：按轴独立检测 + 切 4053 选择脚；
- **不填波形样本、不修改任何 `out[]` 通道**（波形由硬件定时器产生，比 v1 更轻）；
- 触发判据复用 ocd 的 peg 定义与连续计数语义，但**按轴独立计数**（ocd 现状是 ix/iy 联合 OR，信令需要轴归属）；
- ocd 盲期内检测关闭不影响 ocd_sig：ocd_sig 全程武装、独立判断；检测看测量通道 `in[]`，不受 ocd HOLD 期对 `out[]` 的强制值干扰。

## 4. 架构与状态机

每轴一个独立信令状态机实例（X：PB3，Y：PB4）：

```
SIG_OFF ──(本轴连续 peg > OCD_SIG_TRIP_RUN)──→ SIG_ON
   ↑                                              │
   └──(本轴无 peg 稳定持续 OCD_SIG_RELEASE_MS)─────┘
```

- **SIG_OFF（正常）**：本轴 CH 脚低 → 4053 选 X0/Y0，模拟直通。
- **SIG_ON（信令）**：本轴 CH 脚高 → 4053 选 X1/Y1，FB 出口出 1kHz/50% 方波；另一轴不受影响（按轴独立切换）。
- **跳闸**：管线 ISR 内逐样本检查本轴测量值（X 看 `in[1]`、Y 看 `in[3]`），`==0` 或 `==4095` 记为 peg；连续 peg 计数 `>8` 跳闸（同 `OCD_TRIP_RUN` 语义）；非 peg 样本清零连续计数（滤孤立毛刺）。
- **释放（防抖型）**：跳闸后出现第一个非 peg 样本记 `t_clean = HAL_GetTick()`；期间再现任何 peg ⇒ `t_clean` 清零重计；无 peg 稳定持续满 `OCD_SIG_RELEASE_MS`（1s）⇒ 拉低 CH 脚，回模拟直通。若信号持续钉在量程轨（故障未除），永不释放——方波持续报警，这是正确行为。
- 状态迁移直写 GPIO（`HAL_GPIO_WritePin`，寄存器级快，ISR 内安全）；释放计时用 `HAL_GetTick()`（ISR 内读，误差 ≤1ms，对 1s 窗口无影响），同 ocd.c 惯例。

**性能**：包装层每样本开销为几次整数比较（双轴各一个连续计数器），与 ocd 层同量级，远裕于 32µs 死线（ocd 同基础已有上板结论）；不新增定时器中断、不动管线热点代码。

## 5. PWM 生成（硬件定时器，上电常开）

| | X 轴 | Y 轴 |
|---|---|---|
| PWM 源 | TIM2_CH1 | TIM1_CH1 |
| 引脚 | PA5（AF 号待复核，推断 AF1） | PA8（AF 号待复核，推断 AF6） |
| 4053 输入 | X1（DA_FBX 网，经 R6 出板） | Y1（DA_FBY 网，经 R8 出板） |
| 4053 选择脚 | PB3（CH_FBX） | PB4（CH_FBY） |

- **规格**：1kHz、50% 占空、3V3 逻辑摆幅。两路定时器同配：`OCD_SIG_PSC` = 170−1（170MHz/170 = 1MHz 计数）、`OCD_SIG_ARR` = 1000−1（1MHz/1000 = 1kHz）、`OCD_SIG_CCR` = 500（50% 占空）。TIM1 为 16 位定时器，此配置是其可容纳的 1kHz 方案；TIM2 取同配以统一常数。
- **上电即跑、永不启停**：`ocd_sig_init()` 配好即 `HAL_TIM_PWM_Start`；跳闸/释放只写 PB3/PB4 ⇒ 切换瞬时、无启停时序管理（本方案相对 v1 与"跳闸才启定时器"备选的核心收益）。正常态 PWM 被 4053 门在外面空跑。
- **让路**（均在 `ocd_sig_init()` 内，先于定时器启动）：
  - `HAL_DAC_Stop(&hdac1, DAC_CHANNEL_2)`（PA5 让位）；
  - `HAL_DAC_Stop(&hdac4, DAC_CHANNEL_2)` + `HAL_OPAMP_Stop(&hopamp5)`（PA8 让位）；
  - DAC1_CH1 / DAC4_CH1（IN 通道）与 OPAMP4 不受影响；
  - PA5/PA8 改复用推挽（随定时器 GPIO 初始化完成）。
  - 管线内 FB 通道（ch1/ch3）的 DMA 写入照旧保留（DAC 已停，写了无害），管线结构不动。
- ⚠️ **AF 号（PA5=AF1/TIM2_CH1、PA8=AF6/TIM1_CH1）为推断值，实现第一步必须对照 STM32G474 datasheet 复核**，错误配置会导致引脚无输出。

## 6. 参数表（编译期宏，集中 `ocd_sig.h`）

| 宏 | 默认 | 依据 |
|---|---|---|
| `OCD_SIG_ENABLE` | 1U | 总开关，0 = 编译期整体摘除（回退） |
| `OCD_SIG_TRIP_RUN` | 8U | 同 `OCD_TRIP_RUN` 语义，按轴独立计数 |
| `OCD_SIG_RELEASE_MS` | 1000U | 防抖释放窗（用户选定 1s） |
| `OCD_SIG_PSC` | 170U−1 | 170MHz/170 = 1MHz 计数时钟（两路同配） |
| `OCD_SIG_ARR` | 1000U−1 | 1MHz/1000 = 1kHz；TIM1 为 16 位，此为其可容纳方案 |
| `OCD_SIG_CCR` | 500U | 500/1000 = 50% 占空 |
| `OCD_SIG_FORCE` | 0U | 诊断：1 = 强置两轴 SIG_ON（验信令链，不需真过流），用完回 0 |

peg 定义复用 ocd 的语义（==0/==4095）；**ADC 量程修复后与 ocd 一处同步修改**（折返冲顶系 ADC 量程 bug，后续修）。

## 7. 模块接口与挂载

```c
void    ocd_sig_init(void);      /* ocd_init() 之后调用一次: 让路→配定时器→起PWM→包装算法槽 */
uint8_t ocd_sig_state(void);     /* 两轴信令状态: bit0 = X 轴 SIG_ON, bit1 = Y 轴 SIG_ON */
uint32_t ocd_sig_trip_count(void); /* 累计跳闸次数(两轴合计, 观测用) */
```

- 挂载：`ocd_sig_init()` 在 main.c 中 `ocd_init()` **之后**调用，包装手法与 ocd 相同（保存内层指针，最后赋 `ad_da_process_fn`）；
- 包装函数只做检测与 GPIO 切换，`out[]` 无条件委托内层（纯透传语义）；
- `ocd_sig_init()` 内部顺序：停 DAC/OPAMP 让路 → 配并启动两路 PWM → 状态初始化 → 包装算法槽。

## 8. Fail-safe 与已知边界

- **MCU 死机 = 无信令、无切路**：PB3/PB4 下拉保持低 = 模拟直通（与现状一致）；PWM 虽在跑但被 4053 门在外面。信令依赖 MCU 存活，同 ocd 的固有边界；硬件级保护仍靠 F1 保险丝 / LM3886 内部限流。
- **4053 切换瞬间**存在 make/break 毛刺：故障态可接受。
- **总控板认不认方波 = 最大外部未知**：FORCE 先验信令链，再谈检测语义；轴归属协议（含"两线都监测"建议）留给新版总控板自定义协议。
- 信令释放后，若过流再次发生，重新走跳闸流程（无次数限制）。

## 9. 测试、上板与回退

**宿主单元测试**（TDD，`tests/ocd_sig/`，WSL gcc，命令模板同 `tests/ad_da_deglitch` 先例）：

- 状态机：触发（本轴连续 peg >8）、防抖释放（满 1s）、释放期再 peg 清零重计、双轴独立（X peg 不动 Y、反之亦然）、释放后再触发；
- 边界值：样本 ==0 / ==4095 为 peg，==1 / ==4094 非 peg；
- 波形由硬件定时器产生，**单测盖不住，靠上板**。

**上板顺序**：

1. `OCD_SIG_FORCE=1` → 示波器确认：JB3/JB4 出口 1kHz、50%、0↔3V3 方波；PB3/PB4 为高；4053 切路正确；
2. 回 `OCD_SIG_FORCE=0`，等真过流联调（信令链与检测判据分两步，同 v1 策略）；
3. 既有约束不变（JP3 断开等）。

**回退**：`OCD_SIG_ENABLE=0` 整体编译期摘除——所有硬件改动（停 DAC/OPAMP、定时器、GPIO 切换）都封装在 `ocd_sig_init()` 内，摘除后通路恢复现状，无残留。

## 10. Deferred

- **IN 侧振镜保护（取代 ocd 钳位行为）**：本次证实"频率减半（时域拉伸）"不可持续（§1）；候选机制——原地冻结（跳闸瞬间 IN 冻结在当前值，零跳变）、幅值衰减（命令 AC 分量缩半）——已初步分析未拍板；ocd.c 的废弃与替代随该设计一并处理。
- **释放后命令追赶问题**：仅当未来引入 IN 侧干预时才存在（本次 IN 不动，无此问题）。
- **与新版总控板的信令协议**：检测判据、轴归属编码。
- **ADC 量程 bug 修复**：独立任务，修复后同步 peg 判据。
